# 인터뷰 레벨

> 작성일 2026-10-28 · v0.1
> `/ks-plan`, `/ks-dev`가 얼마나 촘촘하게 묻는지 정한다. 숫자 1~5, 5가 가장 촘촘하다.

---

## 0. 한 장 요약

| 항목 | 내용 |
|---|---|
| 정하는 때 | 명령을 처음 부를 때. 인자 맨 앞에 숫자를 쓰면(`/ks-plan 3 …`) 묻지 않는다 |
| 남는 곳 | 작업 폴더의 `level.txt` (숫자 한 글자). 다음 세션과 `/ks-dev`가 이어 쓴다 |
| 바뀌는 것 | 누가 초안을 쓰는가, 한 번에 몇 개를 묻는가, 언제 확인받는가 |
| 바뀌지 않는 것 | 검사 CLI 기준, 단계 순서, 확정·잠금은 사람이 말할 때만, 결과물 모양 |

레벨이 낮아도 문서는 같은 검사를 통과해야 끝난다. 묻는 횟수를 줄이는 대신 AI가 초안을 쓰고, 사람은 모아서 한 번에 확인한다.

## 1. 레벨

| 레벨 | 이름 | 누가 먼저 쓰나 | 한 번에 묻는 것 | 확인받는 때 |
|---|---|---|---|---|
| 5 | 꼼꼼 | 사람 | 칸마다 원문 인용 질문 1~3개 | 매 답 |
| 4 | 촘촘 | 사람, 형식·이어 쓰기는 AI | 질문 최대 4개를 묶어서 | 매 답 + 단계 끝에 AI가 채운 칸 |
| 3 | 보통 | 핵심 칸은 사람, 나머지는 AI | 단계마다 핵심 칸만 (2장) | 단계 끝에 초안 전체 |
| 2 | 가볍게 | AI가 단계 초안 전체 | 사람만 정할 수 있는 것만, 한 번에 | 단계 끝에 한 번 |
| 1 | 최소 | AI가 단계 초안 전체, 정할 것도 추천안으로 | 묻지 않는다 | 단계 끝에 초안을 보여 주고 확정만 한 줄로 |

- 5는 지금까지의 방식 그대로다. 스킬 본문의 루프와 질문 규칙이 5 기준이다.
- 기본값은 없다. 숫자를 받기 전에는 시작하지 않는다.
- 하다가 "더 꼼꼼하게", "대충 가자"고 하면 숫자를 다시 묻고 `level.txt`를 고친다. 이미 쓴 칸은 그대로 둔다.

## 2. 레벨 3에서 묻는 핵심 칸

| 단계 | 사람에게 묻는 칸 | AI가 초안을 쓰는 칸 |
|---|---|---|
| 1 비즈니스 요구사항 | 왜 지금, 목표와 숫자, BR 원문 | 범위 밖, 제약 (요청에 나온 것만) |
| 2 기획 요구사항 | 요구사항, 우선순위 | 페르소나, 완성 기준 |
| 4 상세 스펙 | 갈리는 곳과 갈래, 실패할 때 | 상태표, 조건표, 기본 흐름, 항목 표 |
| 5 개발 스펙 | 결정, 계약, 오류, 작업 순서 | 아키텍처, 데이터, 흐름 설계, 제약, 검증, 규칙 대조 |

## 3. AI가 초안을 쓸 때 지킬 것

- 재료는 사람이 한 말, 앞 단계 문서, 코드에서 읽은 사실, 프로젝트 규칙뿐이다. 요청에 없는 기능은 넣지 않는다.
- BR의 `원문:`은 레벨과 상관없이 사람 말 그대로다. 레벨 1·2는 처음 요청 문장을 원문으로 쓴다.
- 재료가 없어 정할 수 없는 것은 채우지 않고 `## 정할 것`에 남긴다. 숫자 지표처럼 꼭 필요한데 모르면 `(가정)`을 붙인다.
- 레벨 1만 예외로, 정할 것을 추천안으로 채우고 확인 표에 "추천으로 정함"이라고 따로 표시한다. 사람이 하나라도 고치면 그 칸만 다시 쓴다.
- 단계마다 확정을 받아야 다음 틀(`pp.mjs init`)이 생기므로, 어느 레벨이든 단계를 넘을 때 확정은 한 번씩 받는다.
- 확인받을 때는 AI가 채운 칸을 표로 보여 준다: 칸, 쓴 내용, 근거(사람 말·문서 줄·`경로:줄`). 사람이 맞다고 한 뒤에 확정·잠금을 묻는다.
- 형식만 틀린 것은 어느 레벨이든 묻지 않고 고친다.

## 4. 질문 모양

레벨 4 이하에서 한 번에 묻는 것이 많으면 `AskUserQuestion` 한 번에 질문 최대 4개를 넣는다. 그보다 많으면 텍스트로 번호를 매겨 보여 주고 "번호와 답"으로 받는다.

```text
정할 것 3개 (레벨 2 · 기획 요구사항)
1. 근거 BR1 "작성자는 다시 올리지 않고 글을 고칠 수 있어야 한다"
   고친 글에 "수정됨" 표시가 필요한가요?  ① 필요 (추천) ② 필요 없음
2. …
답 예: 1-① 2-② 3 "직접 쓴 답"
```

원문 인용, 추천 표시, 선택지 2~4개 규칙은 레벨 5와 같다.
